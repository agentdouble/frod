# AGENTS.md - Instructions du projet Fraude

## Code

- Ecrire du code modulaire, simple a lire et facile a maintenir.
- Donner une responsabilite claire a chaque module.
- Garder chaque detecteur independant, testable et remplacable.
- Utiliser des types explicites et tester les comportements importants.
- Preferer des regles explicables aux verdicts opaques.

## Memoire de projet

A chaque fois que tu identifies quelque chose qui merite d'etre retenu car il sera utile a la connaissance du projet, ajoute-le dans Obsidian.

- Si le sujet concerne ce projet, ajoute-le dans la memoire projet `Fraude`.
- Si le sujet est general, stocke-le dans `General`.
- Ne cree pas de note vide ou de doublon si une note canonique existe deja.
